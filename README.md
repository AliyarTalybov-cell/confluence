# Confluence в Docker

Локальный тестовый запуск Confluence 8.5.19 и PostgreSQL 15. Понадобятся Docker и Docker Compose.

1. Скопируйте `.env.example` в `.env` и задайте пароль.
2. Запустите `docker compose up -d`.
3. Откройте http://localhost:8090 и в мастере укажите PostgreSQL, сервер `postgres`, порт `5432`, базу и пользователя `confluence`, пароль из `POSTGRES_PASSWORD`.

Данные хранятся в Docker-томах; они не входят в репозиторий. Перед переносом создайте резервные копии базы и тома Confluence. Порт доступен только на локальном компьютере. Для работы требуется подходящая лицензия Atlassian. Используется сторонний образ haxqer с Java-агентом; проверяйте его перед использованием.
